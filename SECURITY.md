# Security Policy

## Supported versions

Only `main` (the latest commit) is supported. This is a personal, actively
developed project with no maintained release branches — fixes land on `main`
and the next published image (`ghcr.io/sjefferson99/simple-activity-tracker-server`)
picks them up.

## Reporting a vulnerability

Please report suspected security issues privately via
[GitHub's private vulnerability reporting](https://github.com/sjefferson99/simple-activity-tracker/security/advisories/new)
rather than opening a public issue. Include:

- What you found and where (file/endpoint/component)
- Steps to reproduce, if possible
- The potential impact

This is a solo-maintained hobby project without a fixed response-time SLA, but
reports will be acknowledged and addressed as soon as reasonably possible.
